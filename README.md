SPA Comments System

Single Page Application (SPA) для добавления и просмотра комментариев. Проект представляет собой древовидную систему комментариев с возможностью прикрепления файлов, защитой от спама и обновлением в реальном времени.

# Основной функционал
- Древовидные комментарии: Каскадная лесенка ответов (рекурсивный вывод на фронтенде).
- Real-time обновления: Новые комментарии появляются без перезагрузки страницы (WebSockets + Django Channels).
- Асинхронная обработка: Сжатие загружаемых изображений (до 320x240) происходит в фоне через Celery, чтобы не блокировать ответ сервера.
- Безопасность (XSS): Строгая фильтрация HTML-тегов. Разрешены только `<a>`, `<code>`, `<i>`, `<strong>`. Вырезаются все опасные скрипты.
- Защита от спама: Интегрирована CAPTCHA при добавлении комментария.
- Файлы: Поддержка загрузки изображений (с предпросмотром через Lightbox) и текстовых файлов (`.txt` до 100 кб).
- Сортировка и Пагинация: Пагинация по 25 сообщений. Сортировка по дате LIFO, email и имени пользователя.
- Кэширование: Базовое кэширование GET-запросов (Redis) для защиты от спама обновлениями.

# Стек технологий
- Backend: Python 3, Django, Django REST Framework.
- Асинхронность: Celery, Redis, Django Channels (Daphne / ASGI).
- Database: MySQL 8.0 (работает в Docker-контейнере).
- Frontend: HTML5, CSS3, Vue.js 3 (CDN), Bootstrap 5.
- Инфраструктура: Docker, Docker Compose.
